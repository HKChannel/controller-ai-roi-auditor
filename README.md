# Controller's AI ROI Audit & "50 That Matter" Scorer

Self-contained, zero-dependency single-page app (`index.html`) built as the interactive companion for the **JPMorganChase Finance AI ROI & Controls** LinkedIn article.

## Live Deployment
- **GitHub Pages URL:** https://hkchannel.github.io/controller-ai-roi-auditor/
- **Repository:** https://github.com/HKChannel/controller-ai-roi-auditor

## Features
- **Tab 1 — Soft Claim vs. Hard Unit ROI Calculator:** Exposes uncredited paper "hours saved" hype (`$2.30M`) against verifiable unit-cost P&L return (`$384K` gross / `$264K` net at JPMorganChase's `-40%` KYC preset), with presets for Prysmian (`-50%` cash prep) and SpectrumIQ (`-80%` research time).
- **Tab 2 — 6-Filter "50 That Matter" & Agentic Control Gate Scorer:** Evaluates unit KPIs, high-volume bottleneck focus, opt-in voluntary adoption, security perimeter, blocking unverified external agents, and human sign-off gates.
- **Executive Actions:** One-click `Copy Controller Audit Memo` and print-ready `Print / Save PDF Memo`.
